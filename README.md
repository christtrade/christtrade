### ChristTrade

Market replay and backtesting for traders, built and run by one person. Replay market history bar by bar, or backtest scripted strategies on it. [christtrade.com](https://christtrade.com)

**[Depth](https://github.com/christtrade/depth)** is the chart behind it, open source under Apache 2.0. A canvas trading chart for React that pans 1M+ candles at 240fps, handles everything from OHLCV bars down to L3 order by order data, and comes with a simulated matching engine and a plugin API.

```bash
npm i @christtrade/depth
```

- Docs: [docs.christtrade.com/depth](https://docs.christtrade.com/depth)
- Devlog: [christtrade.com/devlog](https://christtrade.com/devlog), e.g. [60 to 240fps at 1M candles](https://christtrade.com/devlog/240fps)
